# Як підключити галерею

1. Скопіюйте src/lego/gallery.ts і src/lego/gallery.css у C:\Barbershop\src\lego
2. Вставте блок із gallery-snippet.html у HTML-шаблон сторінки, де має бути галерея
3. Додайте код із gallery-init-example.ts у .ts-файл цієї сторінки
   (перевірте шлях імпорту і список фото)
4. npm start і перевірте на http://localhost:63342
5. Якщо все добре:
   npm run build
   git add -A
   git commit -m "New gallery"
   git push

preview.html можна просто відкрити в браузері, щоб подивитися, як працює галерея.
У проєкт його НЕ копіюйте. Цей файл, ЯК-ПІДКЛЮЧИТИ.md і gallery-*.html/ts теж не копіюйте.
