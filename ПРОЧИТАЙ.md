# Що зробити

1. Замініть webpack.config.js у корені проєкту на цей.
   Інші файли (package.json, tsconfig.json, .gitignore) НЕ чіпайте.
2. Покладіть robots.txt і sitemap.xml у папку src.
3. У кожному HTML-шаблоні замініть свій <title>...</title> на:
   <title><%= htmlWebpackPlugin.options.title %></title>
4. Зберіть, перевірте й відправте:
   npm run build
   Select-String -Path dist\index.html -Pattern "<title>"
   git add -A
   git commit -m "SEO: titles, meta descriptions, sitemap"
   git push
